# 記事用画像

`capture_article_images.py` により、同一の俯瞰カメラと解像度で生成した画像です。

## 実験1: 目標 `(0.65, 0.55)`

- `experiment-1-start.png`: 初期姿勢。手先と目標の距離は0.680074m
- `experiment-1-end.png`: 追従後。距離は0.000008m、到達成功

キャプション案:

> 実験1の開始時と追従後。逆運動学で求めた肩・肘角を位置アクチュエータへ与え、黄色い手先が赤い目標へ到達した。

## 実験2: 目標 `(0.30, 0.80)`

- `experiment-2-start.png`: 初期姿勢。手先と目標の距離は1.096586m
- `experiment-2-end.png`: 追従後。距離は0.000013m、到達成功

キャプション案:

> 目標を左上へ変更した実験2。根元から目標までの距離は実験1とほぼ同じため、肘角はほぼ維持され、肩角が大きく増加した。

## 再生成

```text
uv run python capture_article_images.py
```

生成時のMuJoCoモデルやコードを変更すると画像も変わるため、記事公開時は実験記録に記載した版と一致することを確認します。
