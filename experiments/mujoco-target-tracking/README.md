# MuJoCo目標位置追従実験

2関節アームを目標位置へ移動させ、フィジカルAIの基本ループを数値で観察する最小実験です。学習モデルは使用しません。

## 観察するループ

```text
関節角度と手先位置を観測
  → 目標関節角を計算
  → 各関節へ指令
  → MuJoCoが次状態を計算
  → 手先位置と目標までの距離を再観測
```

## 実行

uvを使用する場合:

```text
uv sync
uv run python run_experiment.py
```

## 画面で確認する

```text
uv run python run_experiment.py --view
```

画面では次の色を確認します。

- 青と緑の棒: 2本のアーム
- 黄色の球: 手先
- 赤い半透明の球: 目標位置

画面を開くと、最初の姿勢で5秒間停止します。その後、アームが約8秒かけて移動します。完了後も画面は自動で閉じません。最終状態を確認してから、自分でウィンドウを閉じてください。

### 今回行うこと

マウス操作や画面内ボタンの操作は不要です。次の順に観察します。

1. 最初の5秒で、アーム全体、黄色い手先、赤い目標点の位置を確認する
2. 青い第1リンクが肩を中心にどう回るか見る
3. 緑の第2リンクが肘を中心にどう曲がるか見る
4. 黄色い手先が赤い目標へ近づくことを見る
5. 動作終了後、黄色と赤がほぼ重なっていることを確認する
6. ウィンドウを閉じ、端末の初期距離・最終距離・成功判定を見る

左右の設定パネルは初期状態で隠し、真上から全体が見えるカメラを使用します。

## 目標位置を変更する

`arm.xml` の次の行にある `pos` の先頭2値が、x座標とy座標です。

```xml
<site name="target" pos="0.65 0.55 0.1" ... />
```

例えば次のように変更します。

```xml
<site name="target" pos="0.30 0.80 0.1" ... />
```

Pythonコードは画面に表示される目標点の座標をモデルから読み取るため、別途変更する必要はありません。

## 記事用画像を生成する

次のコマンドで、2回の実験について開始時と到達後の画像を生成します。

```text
uv run python capture_article_images.py
```

出力先:

```text
article-images/
  experiment-1-start.png
  experiment-1-end.png
  experiment-2-start.png
  experiment-2-end.png
```

各画像には目標位置、手先位置、距離、関節角を記載します。

## 成功条件

- 実行前後の関節角度と手先位置が表示される
- 目標までの距離が小さくなる
- 最終距離が1cm未満になる

## この実験に含めないもの

- 強化学習、模倣学習、VLA
- 障害物回避
- センサーノイズ、通信遅延
- 実機特有の摩擦、発熱、故障
