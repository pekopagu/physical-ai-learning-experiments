# Physical AI Learning Experiments

Zennシリーズ「フィジカルAIをPCで学ぶ」の再現用実験コードです。第1回では、MuJoCoの2関節アームを使い、次の3実験を比較します。

1. 逆運動学による古典制御
2. PPOによる学習ベース制御
3. ルールベース画像処理・CNNによる知覚と古典制御の組み合わせ

結果だけを示すのではなく、実行前に予想し、自分のPCで動きと数値を観察することを目的としています。

## 第1回の結果

| 比較 | 主な結果 |
|---|---|
| 固定20目標・未学習 | 3cm以内 0/20、平均最終距離 1.101532m |
| 固定20目標・PPO | 3cm以内 1/20、平均最終距離 0.689075m |
| 固定20目標・古典制御 | 3cm以内 20/20、平均最終距離 0.024523m |
| 条件C・ルールベース＋古典制御 | 3cm以内 93/200、平均最終距離 0.434341m |
| 条件C・CNN＋古典制御 | 3cm以内 53/200、平均最終距離 0.135514m |

単純な既知座標への到達では古典制御が明確に優位でした。画像知覚ではルールベースが成功時の精度で優れる一方、CNNは複雑な条件で妨害物を誤認したときの大外れを平均的に抑えました。

今回の小実験から得た中心的な見方は、学習ですべてを置き換えるのではなく、規則化しにくい知覚を学習へ任せ、正確な動作を古典制御へ任せる役割分担です。

## 必要な環境

本人が確認した環境:

- Windows 11 Home Build 26200
- Intel Core i7-13620H、32GB RAM
- Python 3.11.15
- MuJoCo 3.11.0
- PyTorch 2.13.0+cpu
- Stable-Baselines3 2.9.0
- `uv`

RTX 4060 Laptop GPUを搭載したPCですが、今回の学習はCPUだけで実行しました。MacBook Airでの確認は端末入手後に別途行う予定です。

## 最短の開始手順

各実験は独立したPython環境です。最初の古典制御実験は次のように実行します。

```text
cd experiments/mujoco-target-tracking
uv sync
uv run python run_experiment.py --view
```

PPOとCNNの実験は、各READMEに従って`predictions.md`へ実行前予想を記入してから進めてください。AIによる技術確認や既存結果を、自分で実行・観察した結果の代わりにしないことを推奨します。
